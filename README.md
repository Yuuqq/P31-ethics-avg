## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅳ 反思篇 · 第14章 新闻传播中的AI伦理**（教材 Tier 2 实验工具）。教材命名："电车难题新闻干预 AVG"。

**学习目标**：在灾难报道、匿名信源保护、AI 内容审核三类伦理困境中完整体验"选择—后果"链条，能够为每一种结局指认其背后的伦理原则与代价。

**核心术语**：新闻伦理（Media Ethics）、最小伤害（Minimize Harm）、知情同意（Informed Consent）、电车难题（Trolley Problem）

**适合对象**：新闻传播专业学生 / 媒体从业者

**课前准备**：建议先读教材第 14 章新闻伦理原则一节；工具打开即用、离线可用，无需账号。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师公开游玩故事线 A"灾难前线"至第一个分叉（先救人还是先拍摄），全班举手投票后再推进到"补拍冒充第一手 → 被网友比对 EXIF 时间戳 → 信用危机"结局，直观呈现一个模糊决定如何滚成职业危机。
2. **上手实操**（20 分钟）：每名学生依次走完 A（灾难现场报道）、B（匿名举报人）、C（AI 生成内容审核）三条故事线，每条至少走向 2 个不同结局 → 记录每次关键选择与对应结局 → 整理一张"选择—后果"对照表，标出让自己从"伦理标杆"跌成"冷血标签"的那次选择。
3. **小组讨论**（8 分钟）：检察机关要求你交出匿名信源时，"守护信源"与"遵守法律"该如何权衡，记者应承担到什么程度？若 AI 参与生成的报道失实，谁该负责——署名记者、编辑部，还是工具开发者？
4. **总结**（4 分钟）：伦理困境没有满分答案，只有"可辩护的决定"——做选择前先问自己：能否向当事人、同行与公众公开说明这样做的理由。

**课后作业**：为本工具新增一条故事线（如"拍不拍自杀者遗容"）：编写 4 个节点、至少 2 个结局的分支剧本（JSON 或文字稿均可），并为每个结局写一句伦理依据。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%
